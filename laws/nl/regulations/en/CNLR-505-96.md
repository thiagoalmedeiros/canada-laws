CNLR 505/96

This area includes all lands described as follows:

That is to say by a line drawn from military grid reference 640540, 163° 15' grid azimuth for a distance of 840 metres to the commencement point;

Then from the above point by a line drawn 269° 30' grid azimuth for a distance of 3,100 metres;

Then from the above point by a line drawn 239° 00' grid azimuth for a distance of 3,025 metres;

Then from the above point by a line drawn 136° 45' grid azimuth for a distance of 1,875 metres;

Then from the above point by a line drawn 120° 00' grid azimuth for a distance of 2,500 metres;

Then from the above point by a line drawn 189° 30' grid azimuth for a distance of 2,100 metres;

Then from the above point by a line drawn 104° 30' grid azimuth for a distance of 3,500 metres;

Then from the above point by a line drawn 82° 00' grid azimuth for a distance of 1,375 metres;

Then from the above point by a line drawn 10° 45' grid azimuth for a distance of 1,335 metres;

Then from the above point by a line drawn 325° 00' grid azimuth for a distance of 1,900 metres;

Then from the above point by a line drawn 10° 45' grid azimuth for a distance of 1,250 metres;

Then from the above point by a line drawn 31° 30' grid azimuth for a distance of 4,150 metres;

Then from the above point by a line drawn 265° 45' grid azimuth for a distance of 2,825 metres;

Then from the above point by a line drawn 243° 45' grid azimuth for a distance of 1,000 metres to the point of commencement.

All bearings refer to Grid North.

The Bay Bulls Big Pond Watershed Area Notice, Newfoundland Regulation 240/78, is repealed.
