BC Reg 91/95

### Prescribed information

1 The Rural Property Taxation Roll is prescribed, for the purpose of section 21 (1) of the Taxation (Rural Area) Act, to contain the following information:

1 Registered Owner(s) Name(s)

2 Mailing Address

3 Property Folio Number

4 Land District

5 Property Narrative Legal Description

6 Actual Use Code

7 Subdistrict Code

8 Tenure Equity Code

9 Common Owner Code

10 Property Location

11 Tax Exemption Code(s)

12 OIC Property Class Code(s)

13 Actual Assessed Value(s)

14 Description of Tax Charges

15 Tax Rates

16 Tax Amounts

17 Total Current Taxes Due

[Provisions of the Taxation (Rural Area) Act, R.S.B.C. 1996, c. 448, relevant to the enactment of this regulation: section 21 (1)]
