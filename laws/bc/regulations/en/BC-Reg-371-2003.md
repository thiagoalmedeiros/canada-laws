### Percentages prescribed

1 The percentages set out in the following Schedule are prescribed for the purposes of the definition of "converted value of land and improvements" in the Schedule to the Community Charter:

| | |
| --- | --- |
| Schedule | |
| Class of Property | Percentage to be applied in respect of that property class |
| 1 | 10% |
| 2 | 35% |
| 3 | 10% |
| 4 | 34% |
| 5 | 34% |
| 6 | 24.5% |
| 7 | 30% |
| 8 | 10% |
| 9 | 10% |

[Provisions of the Community Charter, S.B.C. 2003, c. 26, relevant to the enactment of this regulation: section 282 and section 1 of the Schedule]
