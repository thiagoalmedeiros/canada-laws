# Ministerial Order concerning frequency of the verification of road signs marking a place where a detection system is used to monitor compliance with highway safety rules

Always check the official version before relying on it.

*CQLR c C-24.2, r 27.1*

*Enabling statute: Highway Safety Code (chapter C-24.2, s. 294.1)*

*Updated to 2024-05-02*

**1** The presence and adequacy of road signs marking a place where a detection system is used to monitor compliance with highway safety rules must be verified every 3 months.

**2** (Omitted).
