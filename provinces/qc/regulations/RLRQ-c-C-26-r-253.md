# Règlement sur les stages et les cours de perfectionnement de l’Ordre professionnel des technologistes médicaux du Québec

> **Unofficial version, for personal and non-commercial use only.** © Gouvernement du Québec. Not endorsed by or affiliated with the Government of Quebec. Text obtained from the [official source](https://www.legisquebec.gouv.qc.ca/fr/document/rc/C-26,%20r.%20253) via the [A2AJ Canadian Laws dataset](https://huggingface.co/datasets/a2aj/canadian-laws). Always check the official version before relying on it.

*RLRQ c C-26, r 253*

*Loi habilitante: Code des professions (chapitre C-26, a. 94, par. j)*

*À jour au 2012-09-01*

**1** Donne ouverture à l’application de l’article 55 du Code des professions (chapitre C-26), le cas du technologiste médical qui, dans le cadre de l’exercice de la profession, exerce des fonctions dans le secteur médical clinique après s’en être abstenu pendant plus de 5 ans.

Le technologiste médical doit aviser le secrétaire de l’Ordre d’un tel changement dans les 30 jours de celui-ci.

**2** Le nombre d’années donnant ouverture à l’application de l’article 45.3 du Code des professions (chapitre C-26) est de 5 ans.

**3** Le présent règlement remplace le Règlement sur les stages de perfectionnement des technologistes médicaux (R.R.Q., 1981, c. C-26, r. 174).

**4** (Omis).
