# Arrêté ministériel concernant le type de construction qu’un titulaire de droit exclusif d’exploration, de permis d’exploration minière ou de permis de recherche de substances minérales de surface peut ériger ou maintenir sur les terres du domaine de l’État sans autorisation ministérielle

Always check the official version before relying on it.

*RLRQ c M-13.1, r 3*

*Loi habilitante: Loi sur les mines (chapitre M-13.1, a. 304)*

*À jour au 2024-11-29*

**1** Sur les terres du domaine de l’État, les constructions qui peuvent, sans autorisation ministérielle, être érigées ou maintenues par un titulaire de droit exclusif d’exploration, de permis d’exploration minière ou de permis de recherche de substances minérales de surface sur le terrain faisant l’objet de son droit sont les abris provisoires, démontables et transportables faits d’une matière souple tendue sur des supports rigides.

**2** Les constructions visées à l’article 1 doivent être munies d’une inscription indiquant clairement le numéro ou le code alphanumérique identifiant le droit minier sur le territoire duquel est érigée ou maintenue la construction.

**3** (Omis).
