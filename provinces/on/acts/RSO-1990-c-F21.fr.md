# emblème floral (Loi sur l')

L.R.O. 1990, chap. F.21

### Emblème floral de l’Ontario

1 La fleur connue en botanique sous le nom de trillium grandiflorum et, communément, sous le nom de trillium blanc est l’emblème floral de la province de l’Ontario.
