CNLR 570/96

This area includes all lands described as follows:

That is to say by a line drawn from military grid reference zone 21, 568000 metres east, 5631000 metres north, 89° 30' grid azimuth for a distance of 400 metres to the commencement point;

Then from the above point by a line drawn 341° 00' grid azimuth for a distance of 825 metres;

Then from the above point by a line drawn 273° 30' grid azimuth for a distance of 1,650 metres;

Then from the above point by a line drawn 322° 30' grid azimuth for a distance of 2,650 metres;

Then from the above point by a line drawn 199° 30' grid azimuth for a distance of 2,200 metres;

Then from the above point by a line drawn 300° 00' grid azimuth for a distance of 2,225 metres;

Then from the above point by a line drawn 2° 30' grid azimuth for a distance of 1,975 metres;

Then from the above point by a line drawn 47° 00' grid azimuth for a distance of 5,700 metres;

Then from the above point by a line drawn 126° 30' grid azimuth for a distance of 1,525 metres;

Then from the above point by a line drawn 105° 30' grid azimuth for a distance of 1,975 metres;

Then from the above point by a line drawn 122° 30' grid azimuth for a distance of 1,275 metres;

Then from the above point by a line drawn 217° 00' grid azimuth for a distance of 1,250 metres;

Then from the above point by a line drawn 162° 30' grid azimuth for a distance of 850 metres;

Then from the above point by a line drawn 193° 30' grid azimuth for a distance of 3,975 metres;

Then from the above point by a line drawn 266° 00' grid azimuth for a distance of 850 metres t the point of commencement.

All bearings refer to Grid North.

The East Brook Pond Watershed Area Notice, Newfoundland Regulation 226/78, is repealed.
